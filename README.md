Это небоьшой проект сделаный в свободное время из того хлама что был в кладовке, он позволяет отслеживать состояние основных параметров серверов и виртуальных машин\котейнеров и несколько других вещей которые я планирую добавить позднее. Код\чертежи\схемы выполнены любителем и скорее всего сильно не оптимальны и\или ужасны.  

Структура проекта:
в каталоге 3D_models содержатся фалй итоговой сборки 3д модели в формате stl и a3d (формат сборки компаса 3д)
Также в каталоге находятся два каталога stl и kompas3D, в каталоге stl находятся 3д модели корпуса устройства в формате stl предназначенные для печати на 3д принтере и спорки, в каталоге kompas3D находятся 3д модели в формате m3d и предназначенные для редактирования в исходной программе компас 3д.

Каталог code содержит исходные коды програм и скриптов:
Каталог display_ARM содержит исходный код на c и makefile программы для вывода данных на дисплей.
Каталог scripr_freeBSD содержит скрипт для получения данных с сервера с ОС freebsd (xigmanas)
Каталог script_linux содержит скрипты для получения данных с PVE, PBS, VyOS. также скрпт получения данных о виртуальных машинах и контейнерах. 
Каталог weather содержит скрипт получения данных о текущей погоде и прогнозах погоды.

Каталог resurse  содержит необходимые файлы для работы программы или скриптов (обычно это шрифты, бинарные файлы, изображения, файлы с разметкой (L-файлы)). 

Катаог full содержит поный набор файлов для развертывания
